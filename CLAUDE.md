# Abramov Shop — памятка для Claude

Интернет-магазин бильярдных товаров **abramov.shop** с админкой, кассой для клубов, складом и приложением.
Next.js 16 · React 19 · TypeScript · PostgreSQL · Drizzle ORM · Better Auth. Подробности — в `README.md`.

## Как общаться

- Владелец не программист. Отвечать **по-русски, простыми словами**, без жаргона и названий файлов там, где можно без них.
- Итог работы — что изменилось для людей (покупателя, кассира, склада), а не какие файлы правились.
- Если в задаче есть деньги, остатки или данные покупателей — сказать, что проверено и чем.

## Выкладка — главное правило

- Работа идёт в ветке `claude/…`. **В `main` заливать только по команде владельца** («заливай»).
- Заливка в `main` = выкладка: GitHub прогоняет сборку и автотесты (`.github/workflows/check.yml`),
  при успехе код уходит в ветку `production`, с которой Timeweb обновляет сайт (~3 минуты).
- Перед заливкой — полный прогон автотестов (см. ниже). Красные тесты не заливаем и не отключаем.

## Проверка

- Типы: `npx tsc --noEmit`.
- Автотесты в браузере: `bash e2e/run.sh` (своя база PGlite, заглушки почты, ЮKassa и поставщика; ~6 минут со сборкой).
  Без пересборки: `E2E_SKIP_BUILD=1`. Только часть: `E2E_TESTS="e2e/stock.test.mjs"`.
- В облачной сессии Playwright стоит глобально: перед тестами `ln -sfn /opt/node-tools/node_modules/playwright node_modules/playwright`,
  после — удалить ссылку. Зависимости: `npm ci --ignore-scripts`.
- Новая функция — новый тест в `e2e/*.test.mjs` (в тестах тексты на странице ищутся по-русски, как видит человек).

## База данных

- Схема: `src/db/schema.ts`. Миграция: `npx drizzle-kit generate --name <что_добавили>` → файл в `drizzle/`.
- Миграции применяются сами при старте контейнера. Данные в миграции (UPDATE) дописываются в конец сгенерированного файла
  через `--> statement-breakpoint`.
- Деньги — **в копейках** (integer). Время — по Москве (`Europe/Moscow`).

## Поставщик «Фортуна»

- Сайт `fortu.ru` отвечает **только по TLS 1.2** (на TLS 1.3 рвёт соединение). curl: `--http1.1 --tls-max 1.2`, повторять при обрыве.
- Владелец «Фортуны» разрешил брать **фото**. **Тексты описаний не берём** (SEO) — описание пишет `describe.ts` по характеристикам.
- У варианта товара есть `supplierCode` — код «Фортуны»; по нему составляется заказ поставщику.
- В тестах сайт поставщика заменяет заглушка `e2e/mock-yookassa.mjs` (`FORTU_URL`).

## Чего не делать

- Не копировать тексты и фото чужих сайтов (кроме фото «Фортуны»).
- Не писать персональные данные покупателей в логи, письма поставщикам и внешние сервисы.
- Не менять схему оплаты, бонусов и возвратов без теста на суммы.
- Не удалять данные в базе миграцией без явной просьбы владельца.
